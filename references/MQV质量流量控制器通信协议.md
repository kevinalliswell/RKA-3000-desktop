# MQV 系列质量流量控制器通信协议说明

## 1. 设备配置

本系统共配置 6 台气体质量流量控制器：

| 气体种类 | 型号                 | 数量 |
|----------|----------------------|------|
| 氢气型   | MQV0010CSRH01010C    | 1 台 |
| 其他气体 | MQV0020CSRS01010C    | 5 台 |

## 2. 电文帧格式

### 2.1 帧结构

```
① STX | ② 机器地址 | ③ 子地址 | ④ X | ⑤ 命令/应答 | ⑥ ETX | ⑦ 校验和 | ⑧ CR | ⑨ LF
```

| 字段编号 | 名称     | 字节值         | 说明                              |
|----------|----------|----------------|-----------------------------------|
| ①        | STX      | 02H            | 帧起始符                          |
| ②        | 机器地址 | 2 字节 ASCII   | 16 进制 2 位，如 "01"             |
| ③        | 子地址   | 30H 30H        | 固定为 "00"                       |
| ④        | X        | 58H 或 78H     | 58H(X)=标准地址范围，78H(x)=扩展  |
| ⑤        | 命令/应答| 可变长 ASCII   | 应用层命令或应答数据              |
| ⑥        | ETX      | 03H            | 应用层结束符                      |
| ⑦        | 校验和   | 2 字节 ASCII   | 16 进制 2 位（见 2.3 节）         |
| ⑧        | CR       | 0DH            | 回车                              |
| ⑨        | LF       | 0AH            | 换行                              |

帧分层：
- **数据链路层**：STX … 子地址（固定长度）、ETX … LF
- **应用层**：X … 命令/应答

### 2.2 命令格式（应用层 ⑤）

#### 读数据命令（RD）

```
R D <ADDR4> <COUNT4>
```

| 字段    | 长度 | 说明                                    |
|---------|------|-----------------------------------------|
| `RD`    | 2    | 读数据指令符                            |
| `ADDR4` | 4    | 起始地址（4 位 ASCII 十六进制）         |
| `COUNT4`| 4    | 读取字数（4 位 ASCII 十六进制，16-bit 字）|

地址首位含义：
- `0xxx` → RAM 区（例：`04B6` = RAM 地址 1206）
- `1xxx` → EEPROM 区（例：`1131` = EEPROM 地址 4401）

#### 写数据命令（WD）

```
W D <ADDR4> <DATA4>
```

| 字段    | 长度 | 说明                                    |
|---------|------|-----------------------------------------|
| `WD`    | 2    | 写数据指令符                            |
| `ADDR4` | 4    | 目标地址（4 位 ASCII 十六进制）         |
| `DATA4` | 4    | 写入数据（4 位 ASCII 十六进制，16-bit）  |

#### 应答格式

读数据应答：
```
<END2> <DATA4×N>
```

写数据应答：
```
<END2>
```

| 字段    | 长度   | 说明                             |
|---------|--------|----------------------------------|
| `END2`  | 2      | 结束代码（见第 4 节）             |
| `DATA4` | 4×N    | 每个 16-bit 字用 4 位 ASCII 十六进制表示 |

## 3. 校验和计算

**算法**：将 STX（02H）至 ETX（03H）所有字节（含两端）之和，取低 8 位，求二进制补码，结果用 2 位大写 ASCII 十六进制表示。

**步骤**：
1. 求和：`sum = Σ bytes(STX → ETX)`
2. 取低字节：`low = sum & 0xFF`
3. 求补码：`cs = (0x100 - low) & 0xFF`  （若 low=0 则 cs=0）
4. 转换：`checksum = f"{cs:02X}"` → 2 字节 ASCII

### 3.1 示例：读取 SP/PV（RAM 地址 04B6H，读 2 字）

**发送电文**

```
STX  0   1   0   0   X   R   D   0   4   B   6   0   0   0   2  ETX  A   E  CR  LF
02  30  31  30  30  58  52  44  30  34  42  36  30  30  30  32  03  41  45  0D  0A
```

校验和计算：
- 字节和（10 进制）：2+48+49+48+48+88+82+68+48+52+66+54+48+48+48+50+3 = **850**
- 低字节：850 & 0xFF = **0x52**（82 十进制）
- 补码：0x100 − 0x52 = **0xAE**
- ASCII：`"AE"` → `41H 45H` ✓

**应答电文**（SP=0032H=50，PV=0168H=360）

```
STX  0   1   0   0   X   0   0   0   0   3   2   0   1   6   8  ETX  E   E  CR  LF
02  30  31  30  30  58  30  30  30  30  33  32  30  31  36  38  03  45  45  0D  0A
```

校验和计算：
- 字节和：2+48+49+48+48+88+48+48+48+48+51+50+48+49+54+56+3 = **786**
- 低字节：786 & 0xFF = **0x12**
- 补码：0x100 − 0x12 = **0xEE**
- ASCII：`"EE"` → `45H 45H` ✓

### 3.2 示例：写入设定流量 SP-0 = 0（EEPROM 地址 1131H）

**发送电文**

```
STX  0   1   0   0   X   W   D   1   1   3   1   0   0   0   0  ETX  C   1  CR  LF
02  30  31  30  30  58  57  44  31  31  33  31  30  30  30  30  03  43  31  0D  0A
```

校验和计算：
- 字节和：2+48+49+48+48+88+87+68+49+49+51+49+48+48+48+48+3 = **831**
- 低字节：831 & 0xFF = **0x3F**
- 补码：0x100 − 0x3F = **0xC1**
- ASCII：`"C1"` → `43H 31H` ✓

**应答电文**

```
STX  0   1   0   0   X   0   0  ETX  8   2  CR  LF
02  30  31  30  30  58  30  30  03  38  32  0D  0A
```

## 4. 结束代码

### 正常结束及警告结束

| 结束代码 | 种类 | 内容及动作                                                         |
|----------|------|--------------------------------------------------------------------|
| 00       | 正常 | 正常结束                                                           |
| 21       | 警告 | 由于已分配了由外部切换输入进行设定而使通讯不能设定的地址中写入了数据；不做任何写入处理继续 |
| 23       | 警告 | 由于访问了超过范围的地址而终止读出；由于向超过范围的地址中写入而终止写入；但此前的写入处理有效 |

### 异常结束

| 结束代码 | 种类 | 内容及动作                       |
|----------|------|----------------------------------|
| 40       | 异常 | 地址中未设定 W；废弃了全部电文   |
| 41       | 异常 | WS 或 RS 未设定；废弃了全部电文  |
| 43       | 异常 | ETX(03H) 的设定位置不正确；地址的末尾未设定「,」；废弃了全部电文 |
| 46       | 异常 | 地址异常；废弃了全部电文         |
| 47       | 异常 | 读出数据数异常；废弃了全部电文   |
| 48       | 异常 | 写入数值异常；除异常的地址外进行写入 |
| 99       | 异常 | 未定义命令或其它电文异常；废弃了全部电文 |

## 5. 关键寄存器地址

| 参数   | 存储区   | 地址（十进制） | 地址（十六进制） | 说明                 |
|--------|----------|---------------|-----------------|----------------------|
| SP 当前值 | RAM   | 1206          | 04B6H           | 读当前使用中的 SP 值  |
| PV 当前值 | RAM   | 1207          | 04B7H           | 读当前实际流量值      |
| SP-0   | EEPROM   | 4401          | 1131H           | 写入设定流量 SP-0     |

> **说明**：SP（Set Point）为流量设定值，PV（Process Value）为实际流量测量值。
> 量程对应关系：满量程 = 0x2710（10000 计数单位），通常对应设备铭牌额定流量。

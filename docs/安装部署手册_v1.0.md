# RKA-3000 安装部署手册 v1.0

- 版本：v1.0
- 日期：2026-03-18
- 适用对象：研发、测试、现场实施、客户实验室管理员

## 1. 部署目标

完成 RKA-3000 桌面端在开发机或现场工控机上的安装、依赖配置、数据库初始化和基础启动验证。

## 2. 推荐部署环境

- 操作系统
  - Windows 10/11 64 位
  - macOS 13+（开发验证）
- Python
  - `Python 3.10+`
- 硬件建议
  - CPU：4 核及以上
  - 内存：8GB 及以上
  - 存储：10GB 可用空间
  - 显示器：1920x1080 或以上
- 接口
  - 至少 1 个串口或 USB 转 RS-485 适配器

## 3. 安装步骤

### 3.1 获取代码

```bash
git clone https://github.com/kevinalliswell/RKA-3000-desktop.git
cd RKA-3000-desktop
```

### 3.2 创建虚拟环境

```bash
python3.10 -m venv .venv
source .venv/bin/activate
```

Windows PowerShell:

```powershell
py -3.10 -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3.3 安装依赖

```bash
pip install -U pip
pip install -e ".[dev]"
```

### 3.4 初始化配置

```bash
cp .env.example .env
```

需要调整的关键配置：
- `DB_PATH`
- `SERIAL_PORT`
- `BAUDRATE`
- `MODBUS_UNIT_ID`
- `SIMULATION_MODE`
- `POLL_INTERVAL_MS`

### 3.5 启动应用

```bash
python -m rka_desktop.main
```

## 4. 首次启动检查

- 应用主窗口正常显示
- 可进入配方、监控、报警、设置页面
- 模拟模式下点击“连接设备”不报错
- 可新建并保存一条配方
- 数据库文件在 `data/` 下自动生成

## 5. 现场部署建议

- 优先使用独立 Python 环境，不与其他项目共用
- 串口驱动提前安装并验证
- `.env` 按现场设备地址单独维护
- 首次联调先开启 `SIMULATION_MODE=false` 前做串口回环或基础诊断

## 6. 常见问题

- 问题：`PySide6` 安装失败
  - 建议：升级 `pip`，确认 Python 版本为 3.10+
- 问题：串口无法打开
  - 建议：检查设备名、权限、驱动和占用情况
- 问题：应用启动但无曲线
  - 建议：确认已开始实验，或检查 QtCharts 依赖是否可用

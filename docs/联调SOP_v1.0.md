# RKA-3000 联调 SOP v1.0

- 版本：v1.0
- 日期：2026-03-18
- 适用阶段：现场联调、实验室交付前验证

## 1. 联调目标

验证上位机、RS-485 通信、设备寄存器、实验流程和报警链路是否协同正常。

## 2. 联调前准备

- 代码版本已固定
- `.env` 配置已确认
- 串口驱动与线缆检查完成
- 设备供电、接地、通风和报警设施到位
- 联调记录表已准备

## 3. 联调步骤

### 第一步：软件侧自检

- 启动应用
- 检查页面能正常加载
- 检查数据库可正常初始化
- 检查配方编辑、保存和读取正常

### 第二步：通信联机

- 设置 `SIMULATION_MODE=false`
- 点击“连接设备”
- 验证连接状态与日志输出
- 若连接失败，先排查串口名和地址

### 第三步：基础采集验证

- 读取温度、重量、压力、流量、报警字
- 验证数值是否在合理范围
- 验证轮询是否持续稳定

### 第四步：报警链路验证

- 人工触发可验证报警条件
- 检查报警是否在 UI 中出现
- 检查报警是否写入数据库
- 点击确认报警，检查确认时间和确认人是否写入

### 第五步：实验流程验证

- 选择标准配方
- 启动实验
- 观察曲线、数据表、日志
- 验证停止实验流程

### 第六步：导出验证

- 导出 CSV
- 导出 Excel
- 检查文件字段完整性

## 4. 联调判定

满足以下条件即判定通过：
- 通信稳定
- 数据可持续采集
- 报警可触发、显示、确认、留痕
- 导出功能正常
- UI 无明显阻塞或崩溃

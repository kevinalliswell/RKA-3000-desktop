## 2. `.env` 参数说明

| 变量 | 说明 | 建议值 |
|---|---|---|
| `APP_ENV` | 运行环境 | `dev` / `prod` |
| `DB_PATH` | SQLite 文件路径 | `data/rka.db` |
| `SERIAL_PORT` | 串口名称 | 例如 `/dev/tty.usbserial-0001` 或 `COM3` |
| `BAUDRATE` | 波特率 | `9600` |
| `MODBUS_UNIT_ID` | Modbus 从站地址 | `1` |
| `SIMULATION_MODE` | 是否模拟模式 | `true` / `false` |
| `DEVICE_PROFILE_PATH` | 独立三设备只读诊断的现场配置 JSON 路径 | 留空；联调时指向已核验文件 |
| `POLL_INTERVAL_MS` | 轮询周期 | `500` |

## 3. 串口配置建议

- 旧单设备/PLC 主链路总线类型：RS-485 半双工；下列默认口径不适用于 Azbil CPL 或电子天平。三设备分别配置，见[三设备通讯协议基线](三设备通讯协议基线.md)。
- 旧主链路默认口径：
  - 波特率：`9600`
  - 数据位：`8`
  - 校验位：`N`
  - 停止位：`1`
- 地址规划：
  - 主控温控器、MFC、DAQ 等设备不得重复地址

## 4. 平台侧串口示例

macOS:
- `/dev/tty.usbserial-xxxx`
- `/dev/cu.usbserial-xxxx`

Windows:
- `COM3`
- `COM4`

## 5. 串口联机前检查

- 驱动已安装
- 设备供电正常
- RS-485 A/B 线未接反
- 从站地址已确认
- 现场没有其他程序占用同一串口

## 6. 建议的联机顺序

1. 先用模拟模式验证 UI 和数据库
2. 切换到实机模式
3. 先做连接测试，不直接启动实验
4. 再做轮询读取和报警联动

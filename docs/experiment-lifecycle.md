# 实验生命周期与业务规则

本文描述一次氧化 / 还原实验从待机到归档的完整流程，以及贯穿全程的业务规则。规则在 Python 后端判定
（`domain/` 与 `application/`），界面只显示后端给出的结果与可用操作（`allowed` / `blocked`）。

## 状态

| 状态 | 进入条件 | 系统动作 | 操作者可做 | 出口 |
| --- | --- | --- | --- | --- |
| 待机 | 无运行中实验，且上一次已归档 | 显示最近实验与待办 | 实验准备；修改气体使用上限 | 预检通过后启动 |
| 预检 | 打开“实验准备” | 校验配方可执行、设备回读、报警、样品信息、现场检查 | 填样品、选配方、逐项确认现场检查 | 全部阻断项通过才可“确认启动” |
| 运行 `running` | 启动命令下发成功 | 温度程序一次性下发到温控仪；按配方阶段下发气体；0.5 s 采样 | 手动调气（二次确认 + 原因）、提前结束、紧急停气 | 最后阶段 / 提前结束 / 紧急停气 / 报警 / 执行故障 |
| 惰性处置 `purging` | 运行的任一出口 | 工艺气归零，惰性气按吹扫流量吹扫，停止加热 | 查看；紧急停气（若尚未） | 吹扫满时长 **且** 炉温 < `purge_exit_temperature_c` |
| 待核查 | 处置结束（终态 `completed` / `stopped` / `faulted`） | 标记 `review_state = pending` | 分析、修正试样参数、复核 | 复核后归档 |
| 已归档 | 操作者确认归档 | 冻结指标（KPI）与数据，解锁使用上限 | 导出、生成报告、只读查看 | 回到待机 |

PLC 通路额外保留 `paused`（仅 set-point 模式）与 `interrupted`（PLC 报警位 / 联锁字 / 急停），与 0.8 行为一致。

### 正常出口：配方最后一段

配方规则要求最后一段是纯惰性段。实验进入最后一段即进入惰性处置，所需吹扫时间为
`max(最后一段保持时间, 配方置换时长)`；温度由温控程序的最后一段执行。

### 异常出口

| 出口 | 气体 | 加热 |
| --- | --- | --- |
| 提前结束（需确认，可填原因） | 惰性气按吹扫流量，其余归零 | set-point 模式写 SV = 0；PLC 下发 stop；程序模式提示到面板停止 |
| 紧急停气（**不确认，立即执行**，锁存） | 同上 | 同上 |
| 报警（`alarm` 级软件规则） | 同上 | 同上 |
| 执行故障（升温 / 步骤超时、下发失败） | 同上（尽力下发） | 同上 |
| 采集失败（无法继续监测） | 尽力下发吹扫设定后立即结束 | — |
| 程序关闭 | 尽力下发吹扫设定后结束，标记“处置未按条件完成” | — |

TAIE 温控仪不支持远程启动 / 停止：程序模式下异常结束时，界面明确要求操作者在面板上停止程序。

### 温度程序与阶段同步

程序模式下温控仪自己执行曲线（每个配方段 = 升温段 + 保温段）。后端每次采样读取仪表当前运行段（TAIE `SEG`
寄存器），配方阶段与配气切换跟随仪表：阶段 = (段号 − 1) ÷ 2，只前进不后退。读不到段号时，阶段到温后按时间
计保持，温度回落也不会卡住。set-point 模式仍按炉温到温后计保持。

> 现场需确认：TAIE `SEG` 在程序未运行时的取值，以及段时间单位（`temp_segment_time_unit`）。

## 预检（启动条件）

阻断项：无运行中实验；上一次实验已归档；配方可执行；温度控制方式受当前设备通路支持；设备回读新鲜；
无待确认报警；样品信息完整；现场检查 6 项全部确认。提示项（不阻断）：输入的初始质量与天平读数偏差 > 0.5%。

现场检查是操作者确认，软件无法观测气瓶压力、通风等，确认内容随实验保存（`experiments.checklist`）。

## 配方规则

保存时只校验参数范围；是否**可执行**单独评估，不可执行的配方可以保存但不能在预检中选择：

1. 至少 3 段：惰性置换 · 至少一个反应段 · 惰性收尾；
2. 首尾段只开配方惰性气（N₂ 或 Ar），且保持时间 ≥ 置换时长；
3. 气体符合实验类型：还原 CO / CO₂ / H₂ / CH₄，氧化 CO₂ / O₂（另加惰性气）；
4. 每种用到的气体有 MFC 通道，且不超过设备上限（满量程）；
5. 每段及吹扫流量 ≤ 当前使用上限；
6. 吹扫流量 > 0；
7. 程序模式下段数 ≤ 4（TAIE 8 个程序段）。

每次保存生成新版本并记录原因；实验启动时冻结配方快照（`recipe_snapshot`、`recipe_version`）。

## 气体使用上限

- 设备上限 = MFC 满量程（配置）；使用上限 0 < 值 ≤ 设备上限，按策略版本保存（`gas_limit_policies`）。
- 有实验运行或待核查时锁定；修改前预览受影响的可执行配方；必须填写原因；写入审计。
- 实验启动时冻结使用上限（`limits_snapshot`）；运行中手动调气按快照校验。
- 本机未启用账号，修改人取界面“当前操作者”，不是认证身份。

## 手动调气（命令三态）

前提：运行中、手动模式（切换需二次确认）、无待确认报警、无回读过期设备、填写原因。目标值只允许本次实验类型
允许的气体，且 ≤ 使用上限快照与设备上限。下发后读回 MFC 设定值：一致（±2% 或 0.01 L/min）→ 生效；
不一致 → 命令失败并回退到当前阶段配方值。PLC 通路无设定回读，显示“回读不适用”。

## 软件报警规则

| 规则 | 条件 | 级别 | 动作 |
| --- | --- | --- | --- |
| 炉温超限 | PV > 段目标 + 30 ℃，或 PV > 1600 ℃ | 报警 | 进入惰性处置 |
| MFC 流量偏差 | \|PV − SP\| > 10% SP（且 > 0.05 L/min） | 持续 10 s 警告，60 s 报警 | 报警级进入处置 |
| 天平跳变 | \|Δm\| > 1 g/s | 警告 | 记录，需确认 |
| 回读过期 | 设备持续无有效回读超过 `degraded_fault_seconds` | 警告 | 不自动停机；该段数据不入库；禁止启动与手动调气 |

所有报警都需要填写处理说明后确认；未确认前禁止启动新实验与手动调气，且阻止该实验归档。
多设备通路未接入可燃气 / CO 探头；PLC 通路的硬件报警字与联锁流程保持不变。

## 复核与归档

复核项：实验状态、采样完整性（缺口 = 相邻采样间隔 > 3 个采样周期；时间倒退）、报警确认、配方快照、
操作记录、安全完成依据（吹扫时间与处置后炉温）、质量基准、结束方式。严重度 `block` 阻止归档；`warn`
允许归档但必须填写复核备注。归档时按当前试样参数计算并冻结 KPI，之后试样参数、名称只读。

## 动力学

- 测定区间：从第一个反应段开始到最后一个反应段结束（`reaction_started_at` / `reaction_ended_at`）；旧实验无记录时用全部运行段采样。
- 还原度：失重法（沿用 0.8 公式）；氧化度：增重 ÷ (0.111 × FeO × m₀)，即 FeO → Fe₂O₃ 的理论增重。
- 40% 速率仍为相邻采样差分（定义未改动）。
- 模型拟合（α 0.05–0.70）：界面反应控制、产物层扩散控制（Ginstling–Brounshtein）、Avrami–Erofeev（拟合 n）；
  R² 统一按预测 α 与实测 α 计算。

# USTB-RKA-3000 桌面软件需求和功能清单确认 PRD v1.0

- 文档版本：v1.0
- 编写角色：软件项目经理（桌面端）
- 基线日期：2026-03-06
- 适用系统：铁矿石还原反应动力学试验系统（RKA-3000）
- 技术范围：Python 3.10+ / PySide6 / SQLite3 / RS-485(Modbus RTU)

## 1. 目标与范围

### 1.1 产品目标
构建一套可用于 RKA-3000 实验系统的桌面应用，实现实验流程编排、设备控制、实时采集、数据分析、报告导出与审计追踪，支撑国标 GBT 13241-2017 相关实验执行。

### 1.2 In-Scope（v1.0）
- 设备通信：RS-485 总线、Modbus RTU 多从站轮询。
- 实验流程：等温、程序升温、多段气氛切换、多阶段流程。
- 数据采集：重量、温度、流量、压力、气体组分（若有分析仪输入）。
- 实时可视化：趋势曲线、状态看板、报警提示。
- 本地存储：SQLite 实验记录、配方、设备配置、报警与操作日志。
- 数据导出：CSV/Excel、实验报告（Markdown/HTML/PDF预留）。
- 安全联锁：关键报警显示、联锁状态同步、急停后流程冻结。

### 1.3 Out-of-Scope（v1.0）
- 云端数据平台与多端协同。
- AI 自动建模与高级动力学拟合（保留接口）。
- 复杂权限中心（仅本地基础角色）。

## 2. 用户角色

- 实验员：创建/执行实验，监控曲线，导出报告。
- 工艺工程师：配置配方模板，复盘实验结果，校验动力学参数。
- 设备维护人员：设备联机、寄存器校准、故障排查。
- 管理员：系统配置、用户管理、审计查看。

## 3. 业务流程（主流程）

1. 设备联机与自检（通讯、传感器在线、联锁状态）。
2. 选择或新建实验配方（温度段、气氛段、采样周期、结束条件）。
3. 启动实验并进入实时监控（温度/重量/流量/报警）。
4. 实验中支持暂停/恢复/安全终止。
5. 实验完成后生成结果摘要与原始数据归档。
6. 导出实验报告与数据文件。

## 5. 非功能需求

- 性能
  - 默认采样周期：100ms~1000ms 可配（v1.0 推荐 200ms 起）。
  - UI 刷新不卡顿：实时界面连续运行 8 小时无崩溃。
- 可靠性
  - 通信断链自动重连。
  - SQLite 写入失败可重试，关键数据不丢失（缓存队列）。
- 可用性
  - 关键操作需二次确认（启动、停炉、切气氛）。
- 安全性
  - 联锁报警优先显示，急停状态下禁止继续下发危险控制指令。
- 可维护性
  - 通信层/业务层/UI 分层，寄存器映射可配置。

## 6. 数据实体（v1.0）

- users：用户与角色
- recipes：实验配方元数据
- recipe_steps：配方步骤（温度、升温速率、时长、气体比例）
- experiments：实验主记录（状态、开始结束时间）
- measurements：时序测量数据（重量、温度、流量、压力等）
- alarms：报警事件
- audit_logs：操作审计

## 7. 验收标准（UAT）

1. 可连接 RS-485 设备并完成至少 3 个从站轮询。
2. 可执行一条包含温控段+气氛段的配方，实时曲线可见。
3. 采集数据可落库并可按实验编号检索。
4. 报警出现后界面可提示并记录，支持确认动作。
5. 可导出实验 CSV 与摘要报告。
6. 断开串口后可自动告警并支持重连。

## 8. 里程碑建议

- M1（第1周）：通信层打通（串口+Modbus）、数据库schema、主窗口框架。
- M2（第2周）：实验配方与执行引擎、实时采集与曲线。
- M3（第3周）：报警联锁、导出、日志、联调修复。
- M4（第4周）：现场试运行、UAT、文档封版。

## 9. 风险与待确认项

1. 参数冲突项已冻结为合同口径（2026-03-06）：
   - 炉膛尺寸：`Φ80×400mm（恒温区200mm）`
   - 加热功率：`15kW`
   - 称重量程：`0-300g`
   - N2/CO2 流量：`0-20L/min`
2. 实际寄存器地址、读写权限、缩放系数未最终冻结。
3. 水蒸气发生系统是否纳入 v1.0 自动控制需硬件组确认。
4. 气体分析仪（若外接）通信协议是否统一 Modbus 需确认。

# RKA-3000 实验与报告流程图

下图对应当前桌面程序的可执行流程。人工预检只记录操作员确认；真机的独立急停、供气处置和联锁验收仍按现场 SOP 执行。

```mermaid
flowchart TD
    A[选择或编辑实验配方] --> B[登记样品名称、初始质量和实验员]
    B --> C[检查通信、校准、气路、通风、报警与联锁]
    C --> D{准备信息与现场确认齐全?}
    D -- 否 --> C
    D -- 是 --> E[确认启动并连接设备]
    E --> F{连接与启动命令成功?}
    F -- 否 --> F1[提示失败、保留待机状态并记录原因]
    F -- 是 --> G[创建实验记录、保存试样参数并下发配方设定]
    G --> H[采集温度、质量、压力与气体流量]
    H --> I[测量入库、更新曲线和运行反馈]
    I --> J{报警、联锁或采集故障?}
    J -- 是 --> K[按控制器规则暂停或故障停机]
    K --> K1[记录报警、控制结果和待复核状态]
    K1 --> K2[现场按 SOP 排障与安全处置]
    K2 --> K3{控制器允许恢复?}
    K3 -- 是 --> H
    K3 -- 否 --> M[结束实验并保存最终状态]
    J -- 否 --> L{阶段完成或操作员停止?}
    L -- 继续采集 --> H
    L -- 进入下一阶段 --> G
    L -- 完成或停止 --> M
    M --> N[历史实验：查看原始采样、报警与审计]
    N --> O{需要哪类输出?}
    O -- 实验记录 --> P[报告中心选择实验并预览完整性]
    P --> Q[生成 HTML 或 PDF 技术记录]
    O -- 原始数据 --> R[导出 CSV 或 Excel]
    O -- 还原度分析 --> S[录入并复核 m₀、TFe、FeO]
    S --> T[计算还原度与速率]
    T --> U[导出 Excel 分析报告]
    Q --> V[人工复核数据、方法限制与签署]
    U --> V
```

## 报告边界

- HTML/PDF **技术记录**从所选历史实验读取实验信息、完整原始采样和报警；运行中、故障或无采样的记录会明确标记不完整。
- Excel **分析报告**需要先在数据分析页计算还原度；参数或实验选择变化后，旧结果失效，必须重新计算。
- 当前数据库尚无启动时配方快照、正式数据质量判据、方法版本和电子审签。生成的文件均不能直接视为经批准的正式试验报告。

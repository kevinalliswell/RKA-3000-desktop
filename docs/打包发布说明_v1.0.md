# RKA-3000 打包发布说明 v1.0

- 版本：v1.0
- 日期：2026-03-18

## 1. 目标

将当前 Python 项目打包为可分发的桌面应用目录，便于内部试装与后续客户交付。

## 2. 打包方案

当前建议使用 `PyInstaller`，并统一走仓库内的 spec 与脚本。

安装：

```bash
pip install pyinstaller
```

## 3. 打包命令

推荐脚本：
- [build_pyinstaller.sh](/Users/kevin/CodeWorkSpace/Python Projects/RKA/scripts/packaging/build_pyinstaller.sh)
- [build_windows.ps1](/Users/kevin/CodeWorkSpace/Python Projects/RKA/scripts/packaging/build_windows.ps1)
- [verify_windows_bundle.ps1](/Users/kevin/CodeWorkSpace/Python Projects/RKA/scripts/packaging/verify_windows_bundle.ps1)
- [rka_desktop.spec](/Users/kevin/CodeWorkSpace/Python Projects/RKA/scripts/packaging/rka_desktop.spec)

Linux/macOS 环境可执行：

```bash
./scripts/packaging/build_pyinstaller.sh
```

Windows 环境建议执行：

```powershell
./scripts/packaging/build_windows.ps1 -PythonExe python -Clean
```

## 4. 打包输出

- `dist/RKA3000Desktop/`
- `build/`
- `scripts/packaging/rka_desktop.spec`

## 5. 发布前检查

- `pytest` 通过
- README 已更新
- Release 工作流可用
- `.env.example` 与文档一致
- 文档已同步到当前版本

## 6. 发布步骤

1. 确认 `main` 已合并目标功能
2. 更新 README
3. 执行测试
4. 执行打包脚本
5. 执行 bundle 校验脚本
6. 验证应用可启动
7. 打 tag 并触发 release 工作流

## 7. Windows Smoke Workflow

仓库已补充 Windows smoke workflow：

- `.github/workflows/windows-package-smoke.yml`

用途：

1. 在 `windows-latest` 环境安装依赖
2. 执行 `pytest`
3. 调用 `build_windows.ps1`
4. 上传 `dist/RKA3000Desktop` 作为 artifact

说明：

- 它能帮助我们提前发现 PyInstaller 和 Windows 依赖问题
- 但不能替代真实 Windows 打包机和串口设备验证

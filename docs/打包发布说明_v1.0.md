# RKA-3000 打包发布说明 v1.0

- 版本：v1.0
- 日期：2026-03-18

## 1. 目标

将当前 Python 项目打包为可分发的桌面应用目录，便于内部试装与后续客户交付。

## 2. 打包方案

当前建议使用 `PyInstaller`。

安装：

```bash
pip install pyinstaller
```

## 3. 打包命令

推荐脚本：
- [build_pyinstaller.sh](/Users/kevin/CodeWorkSpace/Python Projects/RKA/scripts/packaging/build_pyinstaller.sh)

也可直接执行：

```bash
pyinstaller \
  --name RKA3000Desktop \
  --windowed \
  --noconfirm \
  --paths src \
  src/rka_desktop/main.py
```

## 4. 打包输出

- `dist/RKA3000Desktop/`
- `build/`
- `RKA3000Desktop.spec`

## 5. 发布前检查

- `pytest` 通过
- README 已更新
- Release 工作流可用
- `.env.example` 与文档一致
- 文档已同步到当前版本

## 6. 发布步骤

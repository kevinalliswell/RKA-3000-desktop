## 1. 冻结结论

### 1.1 产品目标

当前版本冻结为：

- `界面级 MVP`
- 产品定位为 `实验控制与采集软件`

说明：

- 当前版本目标不是正式交付级联调闭环
- 当前版本重点是建立完整 UI、清晰代码结构和可验证的数据采集/写入基础

### 1.2 当前版本必须实现

- 完善的 UI 界面和代码框架结构
- 配方编辑
- 配方执行
- 实时采集
- 设备状态监控（心跳）
- 设备读数
- 参数写入
- 实验记录保存
- 历史查询
- CSV 导出

### 1.3 当前版本明确不做

- 联锁闭环
- 压力采集
- 动力学分析/拟合
- Excel 导出
- PDF/Word 导出
- 设备诊断页
- 校准维护页
- 气体分析仪接入
- 正式控制字闭环

### 1.4 后续版本再做

- 联锁相关能力
- 升温速率配置
- 水蒸气发生系统联动
- Excel/PDF/Word 导出
- 设备诊断页
- 校准维护页
- 动力学分析与拟合

## 2. 业务冻结口径

### 2.1 用户与场景

- 第一优先用户：`实验员`
- 当前主要使用场景：`实验室内部使用`
- 后续目标场景：`正式交付运行`

### 2.2 实验流程

当前版本覆盖：

- 设备联机自检
- 配方选择/新建
- 实验启动
- 实时监控
- 暂停/恢复
- 实验安全终止
- 实验归档

当前版本不覆盖：

- 联锁中断与恢复闭环
- 故障后从中间步骤恢复

### 2.3 配方模型

当前版本配方步骤字段冻结为：

- 目标温度
- 保温时间
- N2 设定
- H2 设定
- CO 设定

后续版本字段：

- 升温速率
- 水蒸气联动

当前版本不纳入：

- 压力目标
- 重量终止条件
- 气氛切换延迟
- 气体分析仪联动

### 2.4 实验控制边界

当前版本只承诺：

- 设备读数
- 参数写入

当前版本不承诺：

- 正式控制字闭环
- 联锁闭环
- 反馈字与运行态完整一致性闭环

### 2.5 在线判据

当前版本不做在线判据。

## 3. 硬件冻结口径

### 3.1 当前版本正式接入

- 温控器
- 流量控制器
- 称重模块

### 3.2 当前版本不接入

- 压力采集
- 联锁/急停模块
- 气体分析仪

### 3.3 后续版本接入

- 水蒸气发生系统
- 联锁相关能力

### 3.4 当前联调目标

冻结为：

- 验证设备读数
- 验证参数下发
- 验证温控制度参数、流量控制器参数和称重模块去皮指令下发

## 4. 数据与导出冻结口径

### 4.1 历史查询最小能力

当前版本需要支持：

- 实验编号
- 配方名称
- 时间范围
- 实验状态

建议补充字段：

- 实验人员
- 配方编号

### 4.2 数据保留

- 原始采样点：全部记录并持久化
- 历史摘要：按实验编号保存到数据库
- 报警日志：按实验编号保存到数据库
- 审计日志：当前版本如非必须，不做强制要求

### 4.3 导出边界

当前版本：

- CSV

后续版本：

- Excel
- PDF
- Word
- 带图正式报告

## 5. UI 与交付冻结口径

### 5.1 首页入口

- `首页导航`

### 5.2 当前版本必须页面

- 首页
- 配方页
- 实验监控页
- 设置页
- 历史查询页

### 5.3 报警相关页面能力

当前版本只要求：

- 当前报警显示

后续版本再做：

- 报警页
- 联锁显示
- 未确认报警列表
- 历史报警查询

### 5.4 交付平台

- 当前正式交付平台冻结为：`Windows`
- 模拟模式冻结为：`仅开发使用`

### 5.5 当前验收最小通过标准

1. 系统架构完整，项目结构清晰
2. 能连接设备并读取实时数据
3. 能下发温控、流量和去皮等参数/指令
4. 能保存实验记录并查询历史实验
5. 能导出 CSV

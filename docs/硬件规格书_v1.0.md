# USTB-RKA-3000 硬件规格书 v1.0（软件联调基线）

- 文档版本：v1.0
- 基线日期：2026-03-06
- 文档目的：定义桌面软件联调所需的硬件接口、通信与安全约束

## 1. 设备总体构成

## 1.1 主体系统
- 高温实验炉（双层风冷、刚玉管、硅钼棒）
- 温度测量与控制（B 型双铂铑热电偶 + 温控器）
- 称重系统（高精度天平/称重传感器）
- 气体供给与混配系统（MFC 多通道）
- 可选水蒸气发生系统（双通道）
- 废气与安全系统（报警、联锁、急停）

## 1.2 控制与采集单元
- 主控 PLC/控制器（Modbus RTU 从站）
- 温控仪（可独立从站）
- MFC 控制器（多从站/多通道）
- DAQ 模块（模拟量采集）
- 工控机/上位机（本桌面软件）

## 4. 通信规格（RS-485 / Modbus RTU）

> 本节是早期集成控制器/PLC 假设下的联调基线，不能作为独立 Azbil MFC 或电子天平的原生协议表。三设备当前协议及现场核验边界见[三设备通讯协议基线](三设备通讯协议基线.md)。

## 4.1 物理层
- 总线：RS-485 半双工，2 线制（A/B）
- 建议波特率：9600/19200 bps（默认 9600）
- 数据格式：8N1
- 终端电阻：120Ω（总线末端）
- 地址规划：1~247（禁止重复）

## 4.2 协议层
- 协议：Modbus RTU
- 功能码：`0x03`（读保持寄存器）、`0x06`（写单寄存器）、`0x10`（写多寄存器）
- 超时建议：200~500ms
- 重试策略：每次轮询最多 3 次，失败置离线并报警

## 5. I/O 与联锁要求

- 输入（采集）
  - 炉温、样品重量、各路流量、炉压、报警状态、急停状态
- 输出（控制）
  - 温度设定、流量设定、运行启停、程序步切换、复位命令
- 联锁（高优先级）
  - 超温、超压、可燃气体报警、风冷异常、急停触发
  - 联锁触发后上位机仅允许“复位/确认”相关安全动作

## 6. 安装与供电条件

- 场地：最小空间 2300×700×1200mm，实验室面积 ≥4㎡
- 环境：10~35℃，湿度 20%~80%，低振动、低电磁干扰
- 电力：380V±5V，50Hz±5Hz，功率 ≥10kW，接地电阻 ≤4Ω
- 安全：强制通风、废气处理、气体报警、消防设施齐备

## 7. 配置清单（联调用）

- 主机系统：RKA-3000 1 套
- 温控器：1 台（支持程序段）
- MFC：5 台（MQV0020BS/05BS）
- 称重系统：1 台（0.001g 级）
- DAQ：1 套
- 工控机：1 套（i5/16G/512G 或同级）
- 软件授权：RKA-Soft Pro（如共存需明确边界）

## 8. 联调验收项

1. 串口稳定轮询 8 小时无异常。
2. 温控 SP 下发与 PV 反馈一致性误差在设定阈值内。
3. MFC 设定与回读一致，切换响应满足 ≤1s（实测）。
4. 报警字与现场报警事件一致并可追溯。
5. 急停触发后控制指令被阻断，复位流程正确。

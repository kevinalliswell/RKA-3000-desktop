## 3. 当前版本必须做的最小闭环

当前版本最小闭环冻结为：

1. 用户可进入首页、配方页、监控页、设置页、历史页
2. 用户可新建或选择配方
3. 软件可读取温度、流量、称重数据
4. 软件可下发温控、流量和去皮参数/指令
5. 软件可保存实验记录
6. 软件可查询历史实验
7. 软件可导出 CSV

## 4. 当前版本明确不做的事项

以下事项不应在当前版本继续扩展：

- 联锁闭环
- 正式控制字闭环
- 压力采集
- 在线判据
- 动力学分析/拟合
- Excel/PDF/Word 导出
- 气体分析仪接入

## 5. 对开发的直接约束

- 不再为联锁闭环继续追加当前版本业务逻辑
- 不再为压力采集追加数据模型和 UI 指标
- 不再把控制字语义扩展成正式控制闭环承诺
- 不再为当前版本追加分析算法和正式报告链路
- 下一轮优先做结构收敛，而不是功能继续扩张

# USTB-RKA-3000 桌面软件 PRD v1.1 增补

- 版本：v1.1
- 日期：2026-03-06
- 基线：在 `PRD_v1.0` 基础上增补
- 参数口径：以《设备买卖合同及技术规格附件》为准

## 1. 增补目标

在 v1.0 基础上交付可直接联调用的操作闭环：
- 配方编辑与维护
- 实时曲线可视化
- 报警确认流
- 实验数据导出（CSV/Excel）

## 2. 增补功能点

| 编号 | 功能 | 描述 | 验收 |
|---|---|---|---|
| FR-11 | 配方编辑器 | 支持步骤新增/删除、保存新配方、更新现有配方 | 可保存并回显步骤参数 |
| FR-12 | 配方执行 | 实验启动绑定选中配方并记录 recipe_id | experiments 中可追溯 |
| FR-13 | 实时曲线 | 温度、重量趋势连续刷新 | 实验运行期间曲线持续更新 |
| FR-14 | 报警确认流 | 报警触发入库，支持人工确认并记录确认人/时间 | alarms 表可见 acknowledged_* 字段 |
| FR-15 | 导出服务 | 基于实验ID导出 CSV 与 Excel | 文件可成功生成且字段完整 |

## 3. 数据结构增补

- `recipe_steps`：配方步骤
- `experiments.recipe_id`：实验与配方关联
- `alarms.acknowledged_by`：报警确认人

## 4. UAT 增补

1. 新建配方后可在下拉框选择并用于启动实验。
2. 实验启动后 `experiments.recipe_id` 不为空。
3. 模拟报警触发后可在界面执行“确认报警”，数据库可见确认时间和确认人。
4. 导出 CSV 与 Excel 成功，包含 `sampled_at/temperature_c/weight_g/...` 字段。
